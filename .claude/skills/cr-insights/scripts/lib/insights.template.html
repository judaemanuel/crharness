Insights

Frases curtas sobre o conjunto de revisões, com o detalhe e a situação de cada uma. Geradas em (dados com hash ).
Como ler. Cada insight nasce vigente: foi conferido com os números de um conjunto de dados. Quando os dados mudam, ele fica a revalidar (a frase continua aqui, com os números de quando foi validada, até alguém confirmar, ajustar ou retirar); quando deixa de fazer sentido, é retirado e fica no histórico com o motivo. Só os vigentes aparecem no dashboard. Os números das frases vêm do facts.json (nenhum é digitado à mão); a interpretação é julgamento de modelo, revisável.
