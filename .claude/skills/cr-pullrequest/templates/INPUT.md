# Fila de PRs

Uma linha por PR. Jira pode ser a chave (`ABC-123`) ou a URL; URL de PR e links colados do Obsidian também são aceitos. A nota é opcional (ex.: "par com PR 33"). Você só adiciona linhas; o estado de cada PR é calculado pela skill (`/cr-pullrequest` sem argumentos) e nunca é gravado aqui.

| PR | Jira | Nota |
|---|---|---|
| https://github.com/<org>/<repo>/pull/<n> | <KEY-123> | |
